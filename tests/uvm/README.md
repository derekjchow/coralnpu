# CoralNPU UVM Testbench

A UVM 1.2 testbench for the `RvvCoreMiniVerificationAxi` DUT with
instruction-level co-simulation against MPACT-Sim, built and run through
Bazel on both Verilator (default, hermetic) and Synopsys VCS.

## Overview

The testbench:

* Instantiates the `RvvCoreMiniVerificationAxi` DUT (generated from Chisel).
* Connects AXI Master, AXI Slave, and IRQ interfaces to the DUT.
* Backdoor-loads a test ELF into the TCMs (`sram_backdoor` DPI).
* Kicks off execution via AXI writes (PC, clock gate, reset release).
* Monitors retired instructions over the RVVI trace interface and checks
  every retirement against the MPACT-Sim reference model via DPI-C.
* Optionally cross-checks against a Spike commit log (3-way check).
* Ends on a `tohost` write, DUT halt/fault, or timeout; the UVM report
  phase prints `** UVM TEST PASSED **` / `** UVM TEST FAILED **`.

## Running the tests

```bash
# Verilator (hermetic, no license needed) — part of the default test set
bazel test //tests/uvm:uvm_base_test_nop

# VCS (requires VCS_HOME, LM_LICENSE_FILE etc., see doc/simulation.md)
bazel test --config=vcs //tests/uvm:vcs_uvm_base_test_nop
```

Test targets are generated by `uvm_test_suite` in `BUILD`: the Verilator
test is `<suite>_<testcase>`, the VCS test is `vcs_<suite>_<testcase>`
(tagged `vcs`, so it is excluded from default builds).

## Running the simulator manually

The simulator binaries can be built and run directly with arbitrary UVM
plusargs:

```bash
bazel build //tests/uvm:coralnpu_uvm_verilator
bazel-bin/tests/uvm/coralnpu_uvm_verilator_build/simv \
  +UVM_TESTNAME=coralnpu_base_test \
  +UVM_VERBOSITY=UVM_HIGH \
  +TEST_TIMEOUT=100000 \
  +TEST_ELF=$PWD/bazel-bin/tests/cocotb/nop_test.elf

# VCS equivalent (runner script filters Synopsys banner noise):
bazel build --config=vcs //tests/uvm:coralnpu_uvm_vcs
bazel-bin/tests/uvm/coralnpu_uvm_vcs +UVM_TESTNAME=coralnpu_base_test ...
```

Supported plusargs (parsed in `tests/coralnpu_test_pkg.sv` and
`tb/coralnpu_tb_top.sv`):

| Plusarg | Default | Meaning |
|---|---|---|
| `+TEST_ELF=<path>` | (required) | ELF loaded into the TCMs and MPACT |
| `+UVM_TESTNAME=<test>` | `coralnpu_base_test` | UVM test to run |
| `+UVM_VERBOSITY=<level>` | `UVM_MEDIUM` | UVM verbosity |
| `+TEST_TIMEOUT=<ns>` | 100000 | Simulation timeout |
| `+ENTRY_POINT=<addr>` | 0 | Program counter start |
| `+MISA_VALUE='h<hex>` | `'h40201120` | MISA given to MPACT |
| `+TOHOST_ADDR=<addr>` | `tohost` symbol | Completion write address |
| `+SPIKE_LOG=<path>` | off | Enable 3-way check against a Spike log |
| `+REGRESSION_LIST=<path>` | — | ELF list for `coralnpu_regression_test` |

## Adding a test

Add an entry to the `uvm_test_suite` in `BUILD`. Any
`coralnpu_v2_binary` ELF target works:

```python
uvm_test_suite(
    name = "uvm",
    binaries = ":coralnpu_uvm",
    tests = {
        "base_test_nop": {"elf": "//tests/cocotb:nop_test.elf"},
        "base_test_rvv_add": {
            "elf": "//tests/cocotb/rvv/arithmetics:rvv_add_int8_m1.elf",
            "timeout_ns": 200000,
            # "uvm_test": "coralnpu_base_test",
            # "extra_plusargs": ["+SPIKE_LOG=..."], "data": [...],
        },
    },
)
```

Prefer one Bazel test per ELF over the in-sim `+REGRESSION_LIST` loop —
Bazel provides the parallelism, caching, and per-test reporting.

## Structure

```
tests/uvm/
├── BUILD                    # Simulator + test targets (rules/uvm.bzl)
├── uvm_test_runner.sh       # sh_test runner; greps the UVM verdict
├── tb/coralnpu_tb_top.sv    # Top-level testbench module
├── env/coralnpu_env_pkg.sv  # UVM environment
├── tests/coralnpu_test_pkg.sv  # Tests and sequences
└── common/                  # Agents and cosim components
    ├── coralnpu_axi_master/ # TB-as-AXI-master agent
    ├── coralnpu_axi_slave/  # Reactive AXI slave model
    ├── coralnpu_irq/        # IRQ/control agent
    ├── transaction_item/    # AXI transaction items
    ├── cosim/               # MPACT DPI checker, RVVI agent, Spike parser
    └── rvvi_agent/          # (unused; candidate for deletion)
```

The MPACT cosim library is `@coralnpu_mpact//sim/cosim:coralnpu_cosim_lib`,
built with the clang host toolchain via the `:cosim_lib_clang` wrapper
(`rules/mpact.bzl`). The DUT Verilog comes from
`//hdl/chisel/src/coralnpu:rvv_core_mini_verification_axi_cc_library_verilog`.

Note: the simulators exit 0 regardless of the UVM verdict, so
`uvm_test_runner.sh` derives pass/fail from the log (`** UVM TEST
PASSED **`, `UVM TEST FAILED`, and the `UVM_FATAL` count).
